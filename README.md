## Описание кейса для настольной игры "Чудесные башни"
Десктоп приложение, позволяющее администрировать процесс игры в рамках одной партии, хранить историю игр, вычислять рейтинги и статистики по игрокам. 
Архитектура проекта

### Model

Содержит бизнес-логику игры:

* Game — игровая сессия
* Player — игрок
* Tower — башня игрока
* Card — игровая карта
* Deck — колода
* DiscardPile — сброс
* Action — игровые действия

### ViewModel

GameViewModel является посредником между пользовательским интерфейсом и игровой логикой.

* обработка действий пользователя
* управление режимами выбора карт
* обновление состояния интерфейса

### View

Интерфейс реализован на Compose Desktop.

Основные компоненты:

* GameScreen
* StatisticsScreen
* PlayerView
* TowerView
* CardView
* CommonCardsView1
* MoveHistoryView

### Service Layer

GameService:

* выполнение действий
* проверка правил игры
* обработка общих карт
* смена хода
* определение победителя
* сохранение результатов игры

### Repository Layer

Для хранения статистики используется SQLite.

GameRepository:

* сохранение завершённых партий
* хранение истории ходов
* получение статистики игроков
* получение истории сыгранных партий
